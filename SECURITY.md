# Security Policy

## Supported Versions

Currently, **The Impostor** is in active development. We only provide security updates and support for the latest version deployed on the `main` branch.

| Version | Supported          |
| ------- | ------------------ |
| v0.x.x  | :white_check_mark: |
| < v0.1  | :x:                |

## Reporting a Vulnerability

We take the security of our players' data seriously. If you discover a vulnerability (such as a database exposure, authentication bypass, or cross-site scripting), please **do not** open a public issue on GitHub.

Instead, please report it privately using one of the following methods:

1. **GitHub Private Reporting**: Go to the **Security** tab of this repository and click **"Report a vulnerability"**.
2. **Email**: Send a detailed report to [eyuele4479@gmail.com].

### What to include in your report:
- A description of the vulnerability and its potential impact.
- Step-by-step instructions to reproduce the issue.
- Any code snippets or screenshots that help explain the problem.

### What to expect:
- **Acknowledgment**: I will acknowledge receipt of your vulnerability report within **48 hours**.
- **Updates**: I will keep you informed about the progress of the fix.
- **Resolution**: If accepted, I will patch the issue as quickly as possible and credit you in the release notes (if you wish). If declined, I will provide a detailed explanation as to why it is not considered a threat.
